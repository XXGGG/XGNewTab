隐私政策

XGNewTab 浏览器扩展

概要：XGNewTab 不收集、存储或传输任何个人数据。所有设置都存储在您的本地设备上。

数据收集

本扩展不会收集任何个人信息，包括但不限于：

  • 浏览历史记录
  • 个人身份信息
  • 使用统计数据
  • IP 地址

数据存储

本扩展唯一存储的数据是您的自定义新标签页网址设置。该数据：

  • 使用浏览器内置的存储 API 存储在您的本地设备上
  • 永远不会传输到任何外部服务器
  • 完全由您控制，可以随时清除

第三方服务

本扩展不使用任何第三方分析工具、跟踪工具或外部服务。当您设置自定义网址时，扩展只是将新标签页重定向到该网址，不会与任何中间服务器进行交互。

权限说明

本扩展请求以下权限：

  • storage - 用于在本地保存您的自定义网址设置和预设列表

所有权限仅用于扩展的核心功能，所有处理都在您的本地设备上进行。

政策变更

本隐私政策的任何未来变更都将在此页面更新。我们建议您定期查看此页面。

联系方式

如果您对本隐私政策有任何疑问，请在我们的 GitHub 仓库 提交 issue。
