Privacy Policy

XGNewTab Browser Extension

Summary: XGNewTab does not collect, store, or transmit any personal data. All settings are stored locally on your device.

Data Collection

This extension does not collect any personal information, including but not limited to:

  • Browsing history
  • Personal identifiable information
  • Usage statistics
  • IP addresses

Data Storage

The only data stored by this extension is your custom new tab URL setting. This data is:

  • Stored locally on your device using the browser's built-in storage API
  • Never transmitted to any external servers
  • Completely under your control and can be cleared at any time

Third-party Services

This extension does not use any third-party analytics, tracking tools, or external services. When you set a custom URL, the extension simply redirects your new tab to that URL - it does not interact with any intermediary servers.

Permissions

The extension requests the following permissions:

  • storage - Required to save your custom URL settings and preset list locally

All permissions are used solely for the extension's core functionality and all processing happens locally on your device.

Changes to This Policy

Any future changes to this privacy policy will be updated on this page. We encourage you to review this page periodically.

Contact

If you have any questions about this privacy policy, please open an issue on our GitHub repository.
